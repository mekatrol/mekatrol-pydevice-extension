# VS Code Extension Notes

This file is retained as a short pointer for developers who expect the default VS Code extension quickstart file.

Mekatrol PyDevice is no longer a scaffolded "Hello World" extension. Use these project files instead:

- `README.md`: user-facing feature overview.
- `tutorial.md`: guided workflow overview.
- `setup_build_publish.md`: setup, build, packaging, and publishing commands.
- `.codex/environment.md`: current Codex-oriented project environment notes.
- `.codex/style-guide.md`: current coding and style guidance.

Useful commands:

```bash
npm run compile
npm run test
npm run package
```
